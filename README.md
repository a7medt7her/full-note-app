# 📝 Note App

A modern, fast, and efficient Note Application built to help users manage their tasks and ideas effortlessly. The app focuses on clean architecture, smooth performance, and a great user experience.

---

## ✨ Features

* ➕ Create notes easily
* ✏️ Edit existing notes
* 🗑️ Delete notes
* ✅ Mark notes as *Completed* or *Not Completed*
* 🔍 Search for a specific note instantly
* 🔄 Multiple sorting options:

  * A → Z
  * Z → A
  * Newest first
  * Oldest first
  * Completed notes
  * Not completed notes

---

## 🧠 State Management

The application uses **BLoC (Business Logic Component)** to separate UI from business logic, ensuring:

* Clean and maintainable code
* Predictable state changes
* Better scalability for future features

---

## 💾 Local Storage

All notes are stored locally using **Hive**, providing:

* Fast read/write performance
* Offline access
* Lightweight and efficient local database

---

## 🛠️ Technologies Used

* Flutter
* Dart
* BLoC
* Hive

---

## 🎯 Goal

This app is designed to be simple yet powerful, making it perfect for daily task management, personal notes, study planning, or work organization.
